# React Authentication Flow

A React application that demonstrates a complete client-side authentication flow.

## Highlights

- Sign up and sign in forms with validation
- Protected routes and redirect handling
- Axios interceptors for authenticated requests
- In-memory access-token handling
- Token refresh preparation and synchronized client state

## Tech stack

React 18, TypeScript, Vite, TanStack Query, Axios, React Router, Context API, ReqRes API.

## Run locally

```bash
npm install
npm run dev
```

Create a `.env` file and add `VITE_REQRES_KEY` if the API key is required.
